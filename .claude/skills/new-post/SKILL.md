# 새 글 만들기

꼬꼬비가 "새 글 써 줘", "/new-post 주제" 처럼 요청하면 이 순서대로 진행해요. 글쓰기 규칙은 `CLAUDE.md`를 따라요.

## 1. 재료 모으기 (꼬꼬비에게 묻기)

아래 중 빠진 것만 한 번에 물어봐요. 꼬꼬비가 바쁘면 주제만으로 시작하고, 나머지는 빈칸으로 남겨요.

1. **주제** (예: "아기 겨울 방한 커버")
2. **넣을 상품과 쿠팡파트너스 링크** (`https://link.coupang.com/a/...`). 링크가 없으면 상품 후보를 먼저 추천하고, 꼬꼬비가 쿠팡파트너스에서 링크를 만들어 주면 넣어요.
3. **직접 써 본 경험 한두 줄** (예: "첫째 날은 답답해했는데 바람 부는 날 확실히 덜 울었어요")
4. **발행 날짜** (없으면 오늘. 미래 날짜면 그날까지 숨겨지는 예약 발행이에요)

## 2. 조사하고 뼈대 잡기

- 사람들이 실제로 검색할 키워드를 정하고(웹 검색 가능하면 활용), 제목·소제목을 먼저 정해요.
- 비슷한 기존 글이 있는지 `content/posts/`를 확인해요. 있으면 내부 링크로 연결하고, 같은 내용을 반복하지 않아요.
- 파일 이름(글 주소)은 영어 소문자와 `-`로 지어요. 예: `baby-winter-stroller-cover.md`

## 3. 글 쓰기

- `content/posts/글주소.md`를 만들어요. 머리말 형식은 `README.md`와 기존 글을 참고해요.
- `cover: /images/posts/글주소/cover.jpg`를 머리말에 넣어요.
- 꼬꼬비 경험이 없는 자리는 `[내 후기: 예) 아이가 처음 썼을 때 반응]`처럼 남겨요. 점검에서 걸리기 때문에 빠뜨리지 않게 돼요.

## 4. 이미지 만들기

- `content/images/글주소.json`에 이미지 내용을 적고 `npm run images -- content/images/글주소.json`을 실행해요.
- 표지 1장 + 정보 카드 2~3장. 본문에 `![키워드 넣은 설명](/images/posts/글주소/파일.png)`으로 넣어요.
- 만든 이미지는 Read로 직접 열어서 글자가 넘치거나 잘리지 않았는지 확인해요. 카드 한 칸의 글머리표는 15자 안쪽이 보기 좋아요.

JSON 형식:

```json
{
  "slug": "글주소",
  "category": "parenting",
  "cover": {
    "label": "육아 · 겨울 외출",
    "lines": ["아기 겨울 외출", "**방한 커버** 고르는 법"],
    "sub": "유모차·아기띠 상황별 추천 3가지",
    "icon": "❄"
  },
  "cards": [
    {
      "file": "check",
      "title": "방한 커버, **이 3가지**만 보세요",
      "sub": "두께보다 바람 막기가 먼저예요",
      "items": [
        { "title": "바람막이", "sub": "겉감 확인", "bullets": ["방풍 원단", "지퍼 틈 없는지"] }
      ]
    }
  ]
}
```

- `**글자**`는 강조색으로 칠해져요. 카드 칸(items)은 2~4개가 보기 좋아요.
- `icon` 대신 `art`에 340×340 SVG를 직접 넣으면 표지 오른쪽 그림이 돼요.
- 번호 동그라미가 필요 없으면 카드에 `"numbered": false`를 넣어요.

## 5. 점검하기

```bash
npm run check -- content/posts/글주소.md
```

- `[내 후기` 빈칸 말고 다른 ❌는 모두 고쳐요.
- 글을 처음부터 끝까지 다시 읽고, 기준과 추천 상품이 서로 어긋나지 않는지 확인해요.

## 6. PR로 올리기

- `post/글주소` 브랜치를 만들고, 글·이미지·JSON을 커밋해서 PR을 열어요.
- PR 설명에는 이렇게 적어요:
  - 글 제목과 한 줄 요약
  - 꼬꼬비가 채워야 할 것 (예: `[내 후기]` 2곳, 쿠팡 링크 없는 상품)
  - 발행 방법: "GitHub에서 PR을 열고 **Merge** 버튼을 누르면 몇 분 뒤 사이트에 올라가요"
- 빈칸이 남아 있으면 PR 점검(Check posts)이 빨간 X로 떠요. 꼬꼬비가 경험을 알려 주면 Claude가 채워서 다시 올려요.

## 7. 꼬꼬비에게 알려 주기

PR 링크와 함께, 꼬꼬비가 할 일만 짧게 알려 줘요. (예: "아기 반응 한 줄만 알려 주시면 채워서 바로 발행할 수 있어요")
