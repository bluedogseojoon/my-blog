# 개선 기록

꼬꼬비가 지적한 내용을 날짜별로 남겨요. 최신 기록이 위에 와요.
같은 지적이 **두 번째** 나오면 `CLAUDE.md` 규칙의 해당 줄을 고치고, 가능하면 `scripts/check-post.mjs`에 점검을 추가해요.

형식:

```
## YYYY-MM-DD 짧은 제목
- 꼬꼬비: "원문 그대로"
- 문제 → 바꾼 것 (파일 이름). 규칙/점검으로 올렸는지.
```

## 2026-10-27 굵은 글씨 별표가 그대로 보임
- 꼬꼬비: "** ** 이 표시는 없애죠"
- `**"인용"**예요`처럼 따옴표 뒤에 글자가 붙으면 굵게 안 바뀜 → 3곳 수정. `CLAUDE.md` 규칙 추가, `check-post.mjs`에 별표 점검 추가.
