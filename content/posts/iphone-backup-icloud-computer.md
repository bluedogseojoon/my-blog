**결론부터 말하면, 아이폰 백업은 "아이클라우드 백업 켜 두기"가 가장 쉬워요.** 설정 > 내 이름 > iCloud > iCloud 백업에서 켜 두면, 밤에 충전하는 동안 와이파이로 알아서 백업돼요. 아이클라우드 공간이 모자라면 컴퓨터로 백업하면 돼요.

휴대폰을 바꿀 때, 서비스센터에 맡길 때, 업데이트하기 전에 꼭 듣는 말이 "백업은 해 두셨어요?"예요. 아이 사진과 연락처, 메신저 대화가 한 번에 날아가면 되돌리기 어렵죠. 이 글은 두 가지 백업 방법을 순서대로 정리했어요. (iOS 26 기준이라 버전에 따라 메뉴 이름이 조금 다를 수 있어요.)

![아이폰 백업 방법 비교: 아이클라우드 백업과 컴퓨터 백업 차이](/images/posts/iphone-backup-icloud-computer/compare.png)

## 아이클라우드 백업과 컴퓨터 백업, 뭐가 다를까요?

| 구분 | 아이클라우드 백업 | 컴퓨터 백업 (맥·윈도우) |
| --- | --- | --- |
| 저장 위치 | 애플 서버(인터넷) | 내 컴퓨터 |
| 필요한 것 | 와이파이, 아이클라우드 공간 | 케이블, 컴퓨터 빈 공간 |
| 자동 백업 | 충전 + 와이파이 + 잠금 상태면 자동 | 연결했을 때 직접 백업 |
| 암호화 | 항상 암호화 | "로컬 백업 암호화"를 켜야 해요 |
| 이럴 때 좋아요 | 평소에 꾸준히 백업할 때 | 아이클라우드 공간이 모자랄 때 |

둘 중 하나만 해도 되지만, 휴대폰을 바꾸기 직전처럼 중요한 순간에는 두 가지를 다 해 두면 더 안심이에요.

## 아이클라우드 백업 켜는 법

![아이폰 아이클라우드 백업 위치: 설정 내 이름 iCloud에서 iCloud 백업](/images/posts/iphone-backup-icloud-computer/screen-icloud.png)

1. **와이파이**에 연결해요.
2. **설정**을 열고 맨 위의 **내 이름**을 눌러요.
3. **iCloud**를 누르고, 목록에서 **iCloud 백업**을 눌러요.
4. **이 iPhone 백업**이 켜져 있는지 확인해요.

![아이폰 iCloud 백업 화면: 이 iPhone 백업 켜기와 지금 백업](/images/posts/iphone-backup-icloud-computer/screen-backup.png)

켜 두면 아래 세 가지가 맞을 때 자동으로 백업돼요.

- 충전기에 연결되어 있을 때
- 와이파이에 연결되어 있을 때
- 화면이 잠겨 있을 때

그래서 밤에 충전기를 꽂아 두고 자는 습관이 있으면 따로 할 일이 거의 없어요.

## 지금 바로 백업하기

휴대폰을 바꾸거나 수리 맡기기 직전에는 자동 백업을 기다리지 말고 바로 해 두세요.

1. 와이파이에 연결해요.
2. **설정 > 내 이름 > iCloud > iCloud 백업**으로 들어가요.
3. **지금 백업**을 눌러요. 끝날 때까지 와이파이를 끊지 않아요.
4. 다 되면 **지금 백업** 아래에 가장 최근 백업 날짜와 시간이 나와요. 오늘 날짜인지 확인해요.

사진이 많으면 처음 백업은 시간이 꽤 걸릴 수 있어요. 충전기를 꽂아 두고 하는 게 좋아요.

**공간이 부족하다고 나오면?** 아이클라우드 무료 공간은 5GB예요. 경고가 나오면 화면 안내에 따라 저장 공간을 추가로 구입하거나, 아래 컴퓨터 백업을 쓰면 돼요. 오래된 백업이나 안 쓰는 앱 데이터를 지워서 공간을 만드는 방법도 있어요.

## 컴퓨터로 백업하는 법 (맥·윈도우)

![아이폰 컴퓨터 백업 순서: 케이블 연결, 신뢰, 로컬 백업 암호화, 지금 백업](/images/posts/iphone-backup-icloud-computer/computer.png)

**맥 (macOS Catalina 이후)**

1. 아이폰을 케이블로 맥에 연결해요. 연결을 허용할지 물으면 **허용**을 눌러요.
2. **Finder**를 열고 왼쪽 사이드바에서 내 아이폰을 눌러요.
3. "이 컴퓨터를 신뢰하겠습니까?"가 나오면 맥과 아이폰 모두에서 **신뢰**를 누르고, 아이폰 암호를 입력해요.
4. **로컬 백업 암호화**를 선택하고 암호를 만들어요.
5. **지금 백업**을 누르고 끝날 때까지 기다려요.

**윈도우 PC**

1. 마이크로소프트 스토어에서 **Apple 기기** 앱을 받아요. (예전처럼 iTunes를 써도 돼요.)
2. 아이폰을 케이블로 연결하고, 아이폰에서 **신뢰**를 누르고 암호를 입력해요.
3. 앱에서 내 아이폰을 선택하고, 백업 항목에서 이 PC로 백업하도록 고른 뒤 백업을 시작해요.
4. 맥과 마찬가지로 **로컬 백업 암호화**를 켜 두는 게 좋아요.

**암호화 암호는 꼭 적어 두세요.** 애플은 이 암호가 없으면 백업을 복원할 수 없다고 안내해요. 대신 암호화를 켜야 건강·활동 데이터와 키체인(저장된 비밀번호)까지 백업에 들어가요.

## 백업에 안 들어가는 것도 있어요

백업이라고 휴대폰의 모든 것이 그대로 저장되는 건 아니에요. 애플 안내에 따르면 아래는 백업에 들어가지 않아요.

| 백업에 안 들어가는 것 | 이유·대신 |
| --- | --- |
| 이미 아이클라우드에 동기화된 것 | 아이클라우드 사진, 메시지 등은 따로 저장돼 있어요 |
| Face ID·Touch ID 설정 | 새 휴대폰에서 다시 등록해요 |
| Apple Pay 정보 | 새 휴대폰에서 카드를 다시 추가해요 |
| 앱스토어 앱 자체 | 복원할 때 다시 내려받아요 |

컴퓨터 백업은 암호화를 켜지 않으면 건강·활동·키체인 데이터도 빠져요.

카카오톡처럼 앱마다 대화 백업을 따로 하는 앱도 있어요. 휴대폰을 바꾸기 전에는 자주 쓰는 앱 설정에서 대화 백업을 한 번 더 확인해 두세요.

## 마무리

정리하면 이렇게 기억하면 돼요.

1. **설정 > 내 이름 > iCloud > iCloud 백업**에서 **이 iPhone 백업**을 켜 두기.
2. 충전 + 와이파이 + 잠금 상태면 **자동 백업**, 급할 땐 **지금 백업**.
3. 아이클라우드 공간이 모자라면 **맥**(Finder)이나 **윈도우**(Apple 기기 앱)로 백업.
4. 컴퓨터 백업은 **로컬 백업 암호화**를 켜고 암호를 꼭 적어 두기.
5. Face ID, Apple Pay, 일부 앱 대화는 **백업에 안 들어가니** 따로 챙기기.

아이클라우드 공간이 금방 찬다면 [아이폰 저장공간 부족할 때 정리 순서](/posts/iphone-storage-full-cleanup-order)도 함께 보세요.
